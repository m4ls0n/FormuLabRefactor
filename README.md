# FormuLab (Refactor Version)

> **Статус проекта:** В разработке 
>
> Данный репозиторий является развитием дипломной работы «Desktop-приложение для обработки текста, полученного nbconvert и содержащего формулы Latex».
> Оригинальный прототип: [FormuLab](https://github.com/lkhorasandzhian/FormuLab).

##  Описание

**FormuLab** — это десктопное приложение на Python (Tkinter) для конвертации Jupyter Notebook (`.ipynb`) в формат LaTeX (`.tex`).

Программа решает проблему сложного переноса вычислений, кода и графиков из среды разработки в научные статьи и отчеты. Она позволяет пользователю выборочно конвертировать ячейки и автоматически исправляет ошибки форматирования, возникающие при стандартном экспорте через `nbconvert`.

##  Цели доработки

В рамках текущей работы в приложение вносятся следующие изменения и новые функции:

### 1. Улучшение функционала выбора контента
* **Групповое выделение:** Реализация быстрого выбора ячеек по типу: «Только текст», «Только код» или «Только выходные данные».
* **Гибкая фильтрация:** Возможность снять или добавить выделение для всех ячеек сразу.

### 2. Исправление дефектов и улучшение алгоритмов
* **Работа с графикой:** Обеспечение корректного извлечения **всех** изображений из ячейки (исправление ошибки базовой версии, когда извлекался только первый график).
* **Заголовки Markdown:** Корректный алгоритм определения уровня вложенности заголовков (H1–H6) и их преобразование в соответствующие теги LaTeX.
* **Математические формулы:** Автоматическое форматирование длинных формул с использованием окружения `breqn` для предотвращения выхода текста за границы печатной области.

### 3. Пакетная обработка файлов
Реализация логики работы с папками (несколькими файлами сразу) с двумя стратегиями объединения:
* **Слияние:** Создание единого `.tex` файла, где содержимое ноутбуков идет последовательно.
* **Модульная структура:** Генерация главного файла `main.tex` и подключение отдельных частей через команду `\input{...}`.

## Технологический стек

* **Язык:** Python 3.10+
* **GUI Фреймворк:** Tkinter / CustomTkinter
* **Ядро конвертации:** `nbconvert`, `pandoc`
* **Сборка:** PyInstaller (для создания `.exe`)
