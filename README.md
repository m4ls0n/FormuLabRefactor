# FormuLab (Refactor Version)

> **Статус проекта:** завершен
>
> Данный репозиторий является развитием дипломной работы «Desktop-приложение для обработки текста, полученного nbconvert и содержащего формулы LaTeX».
> Оригинальный прототип: [FormuLab](https://github.com/lkhorasandzhian/FormuLab).

## Описание

**FormuLab** — десктопное приложение на Python и Tkinter для конвертации Jupyter Notebook (`.ipynb`) в LaTeX (`.tex`).

Приложение помогает переносить текст, код, графики и математические формулы из Jupyter Notebook в материалы для отчетов, статей и учебных работ. Пользователь может выбрать нужные ячейки, преобразовать их в `.tex`, просмотреть результат и сохранить итоговый файл вместе с извлеченными изображениями.

## Основной функционал

* Загрузка одного `.ipynb` файла
* Загрузка папки с несколькими `.ipynb` файлами
* Отображение списка загруженных файлов в режиме пакетной обработки
* Индивидуальный выбор ячеек для каждого файла
* Визуальная отметка напротив файла, если в нем выбраны ячейки
* Быстрые фильтры выбора:
  * `Выделить все (файл)` и `Снять выделение (файл)`
  * `Только текст (файл)`, `Только код (файл)`, `Только выходные данные (файл)`
  * `Выделить все (все)` и `Снять выделение (все)`
  * `Только текст (все)`, `Только код (все)`, `Только выходные данные (все)`
* Конвертация выбранных ячеек в LaTeX через `nbconvert`
* Добавление оглавления (для корректного появления пунктов и ссылок в PDF `.tex` файл нужно скомпилировать дважды)
* Добавление нумерации заголовков
* Извлечение нескольких картинок из одной или нескольких ячееек кода без конфликта имен
* Скачивание remote картинок из Markdown ссылок и сохранение их рядом с итоговым `.tex`
* Форматирование длинных блочных математических формул через `dmath*` из пакета `breqn`
* Пакетный экспорт в двух режимах:
  * слияние всех выбранных ячеек из всех notebook файлов в один `.tex`
  * модульная структура: `main.tex` и отдельные `.tex` файлы в папке `parts/`, подключаемые через `\input{...}`

## Выполненные доработки

### Markdown и LaTeX

* Реализовано определение уровней Markdown заголовков H1-H6
* Заголовки преобразуются в LaTeX блоки с соответствующими размерами и отступами
* Добавлены служебные маркеры заголовков для работы оглавления и нумерации без использования стандартных run in заголовков `\paragraph` и `\subparagraph`
* Исправлена обработка заголовков внутри обычных строк и защищена обработка fenced code blocks

### Изображения

* Исправлена обработка нескольких картинок при выводе в нескольких ячейках
* Теперь нет конфликтов metadata.filename, из-за которых nbconvert мог падать при повторяющихся названиях картинок
* В пакетном режиме изображения не дублируются при одновременной подготовке общего файла и отдельных частей
* Remote картинки из Markdown ссылок скачиваются в папку изображений и подключаются как локальные файлы; если скачать картинку не получилось, то формируется безопасная текстовая ссылка, чтобы компиляция LaTeX не падала

### Математические формулы

* Блочные Markdown формулы автоматически переводятся в dmath* из пакета breqn
* Это предотвращает выход длинных выражений за границы
* Подключение breqn добавляется в начало генерируемого LaTeX файла
* Длинные inline-формулы с `\displaystyle` также переводятся в переносимое окружение

### Пакетная обработка

* Файлы из папки загружаются в алфавитном порядке
* В окне выбора отображается список всех загруженных файлов
* При выборе файла отображаются только его ячейки
* Быстрые фильтры могут применяться к текущему файлу или ко всем файлам сразу
* Есть два вида сохранения: единый `.tex` и модульная структура `main.tex + parts/*.tex`
* Для модульной структуры корректно сохраняются локальные, извлеченные и remote картинки, используемые в отдельных частях документа

### Тестирование

* Добавлены модульные тесты на `pytest`
* Тесты изолированы от Tkinter и проверяют:
  * Markdown заголовки
  * извлечение картинок
  * обработку длинных формул
  * финализацию заголовков, оглавления и нумерации
  * модульный batch экспорт
  * алфавитный порядок загрузки notebook файлов из папки
  * корректное сохранение изображений и remote картинок в модульной структуре

## Запуск приложения

### Требования

* **Операционная система Windows 10 или выше**

Перед запуском установить:

* **Python 3.10+**
* **Pandoc** - обязателен для работы `nbconvert`: [https://pandoc.org/installing.html](https://pandoc.org/installing.html)
* **LaTeX дистрибутив** - нужен для компиляции `.tex` в PDF, например [MiKTeX](https://miktex.org/download) или [TeX Live](https://www.tug.org/texlive/)

### Запуск из терминала VS Code

Откройте папку проекта в VS Code и выполните команды в терминале PowerShell:

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m src.main
```

### Запуск через exe-файл

После сборки приложения через PyInstaller готовый исполняемый файл находится по пути:

`dist/FormuLab/FormuLab.exe`

Для запуска достаточно открыть `FormuLab.exe` двойным щелчком мыши.

Важно: приложение собрано в формате `one-folder`, поэтому файл `FormuLab.exe` должен находиться рядом с папкой `_internal`. При переносе приложения на другой компьютер необходимо копировать всю папку `dist/FormuLab`, а не только один exe-файл.

Для работы приложения через exe-файл не требуется установленный Python, однако внешние инструменты остаются обязательными:

* Pandoc — для конвертации notebook-файлов;
* LaTeX-дистрибутив, например MiKTeX или TeX Live — для компиляции `.tex` в PDF.


## Как пользоваться приложением

1. Запустите приложение командой `python -m src.main`
2. На главном экране выберите один `.ipynb` файл или папку с notebook файлами
3. В окне выбора ячеек отметьте нужные ячейки вручную или используйте быстрые фильтры
4. При загрузке папки выберите файл в списке слева, чтобы увидеть его ячейки. Галочка напротив имени файла означает, что в нем уже есть выбранные ячейки
5. Нажмите `Конвертировать`
6. На экране финализации проверьте предпросмотр `.tex`, включите оглавление или нумерацию заголовков, если это нужно
7. Если загружена папка, выберите тип экспорта: единый файл или модульная структура
8. Нажмите `Сохранить файл` и выберите место сохранения
9. Если нужен pdf, скомпилируйте сохраненный `.tex` через скачанный LaTeX дистрибутив. Для появления оглавления компиляцию нужно выполнить два раза

## Запуск тестов

Для запуска тестов установите dev зависимости:

```powershell
python -m pip install -r requirements-dev.txt
```

Запустите тестовый набор:

```powershell
python -m pytest
```

## Структура репозитория

### Исходный код

`src/` — содержит исходный код приложения.

### Основные файлы приложения

* `main.py` — точка входа, инициализация Tkinter и запуск приложения.
* `formulab_application.py` — управление жизненным циклом приложения и переключением экранов.

### Utility файлы

`utils/` — содержит утилиты по работе с файлами.

* `__init__.py` — инициализация пакета `utils`.
* `formulab_exceptions.py` — Специализированные исключения приложения FormuLab.
* `windows_subprocess.py` — Скрытие консольных окон дочерних процессов от основного процесса приложения FormuLab, а также патч для фонового запуска внешних утилит (например, pandoc) без мерцания терминала.

### MVC структура

---

`MVC/` — Model-View-Controller архитектура для компонент приложения.

#### Models

`models/` — компоненты моделей.

* `__init__.py` — Инициализация пакета models.
* `main_menu_model.py` — Модель главного меню.
* `cell_selector_model.py` — Модель выбора ячеек.
* `file_finalization_model.py` — Модель доработки файла.

#### Views

`views/` — графические представления Tkinter.

* `__init__.py` — Инициализация пакета views.
* `main_menu_view.py` — Представление главного меню.
* `cell_selector_view.py` — Представление выбора ячеек.
* `file_finalization_view.py` — Представление доработки файла.

#### Controllers

`controllers/` — компоненты контроллеров.

* `__init__.py` — Инициализация пакета controllers.
* `main_menu_controller.py` — Контроллер главного меню.
* `cell_selector_controller.py` — Контроллер выбора ячеек.
* `file_finalization_controller.py` — Контроллер доработки файла.

### Tests

`tests/` — модульные тесты бизнес-логики.

* `test_cell_selector_model.py` - тесты Markdown, картинок и математических формул
* `test_file_finalization_model.py` - тесты оглавления, нумерации и модульного экспорта
* `test_main_menu_model.py` - тесты загрузки папки и алфавитного порядка notebook файлов
* Всего тестовый набор имеет 18 тестов: 5 для конвертации ячеек, 12 для финализации LaTeX и изображений, 1 для загрузки папки
* В `test_file_finalization_model.py` дополнительно проверяются синхронизация путей к изображениям, повторные ссылки на одну картинку, одинаковые временные имена в разных частях, локальные ссылки на изображения, скачивание remote-картинок и fallback при ошибке скачивания
